# Découpe

App de montage vidéo dans le navigateur : importer une vidéo, la couper, l'exporter au format vertical TikTok (1080 × 1920).
Les vidéos ne quittent jamais l'ordinateur : tout le traitement se fait dans le navigateur.

## Lancer l'app

```bash
npm install
npm run dev      # ouvre http://localhost:5173
```

Autres commandes : `npm run build` (version finale dans `dist/`), `npm run lint`.
